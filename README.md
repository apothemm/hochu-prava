# #ХОЧУПРАВА — GitHub Pages

Сайт: https://apothemm.github.io/hochu-prava/

Опубликован из предоставленного архива hochu-prava-updated.zip. Дизайн, страницы, изображения, документы и локальный помощник сохранены.

Это визуальная демонстрация. Формы и окно чата сохранены для просмотра, но отправка отключена и обозначена в интерфейсе. GitHub Pages не запускает исходный Node.js server.js. Персональные данные и заявки здесь не собираются. Исходный сервер и локальное хранилище заявок не публикуются.

Изменения для размещения: адреса canonical, Open Graph и sitemap указывают на GitHub Pages; добавлен .nojekyll. Внешние изображения и шрифты загружаются с адресов, указанных в исходном сайте.

## Запуск локально

```sh
python -m http.server 8766
```

Публикация: ветка main, корень репозитория.
